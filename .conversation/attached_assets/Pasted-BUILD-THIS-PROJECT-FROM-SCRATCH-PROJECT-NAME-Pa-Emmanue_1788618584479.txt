==================================================

Create:

/check-in

The usher must be able to use the phone's camera directly inside the website to scan the guest QR code.

Do NOT require:
- Google Lens
- a separate QR scanner app
- guest login
- guest password

When scanned:

If valid and unused:
SHOW:

"CHECK-IN SUCCESSFUL"

Show:
- Guest name
- RSVP status
- time checked in

Then mark the invitation as checked in.

If the same QR is scanned again:

SHOW:

"ALREADY CHECKED IN"

Show:
- Guest name
- original check-in time

Never allow the same guest to be checked in twice.

Also provide a manual fallback:

"Enter Invitation Code"

This must work if the camera cannot scan.
